# HuaBao AI Employee — Phase 1 MVP

This is a browser-based prototype of an internal AI platform that includes:
1. **HSE AI Assistant**
2. **Engineering / Boiler Performance**
3. **ESG Data Analysis**
4. **IT Helpdesk**
5. **Management Dashboard**

## Usage
Simply double-click `index.html` to open the application in your browser.

## Current Version
This is a **frontend MVP demonstration version**.
The AI analysis currently uses local rule-based logic for demonstration purposes and is **not connected to a real LLM/API, company database, or knowledge base**.

## Next Development Steps
* Integrate enterprise LLM/API
* Build a company knowledge base with RAG
* Implement user authentication and role-based access control
* Support Excel/Word/PDF file uploads
* Implement AI-powered HSE photo recognition
* Integrate Boiler/WWTP/Energy data APIs
* Automate ESG/GHG calculations
* Implement IT ticket management
* Integrate WeCom/Email notifications
* Implement audit logs and data security
