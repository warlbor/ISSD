# HuaBao AI Employee — Phase 1 MVP

这是一个可直接在浏览器打开的内部AI平台原型，包含：
1. HSE AI Assistant
2. Engineering / Boiler Performance
3. ESG Data Analysis
4. IT Helpdesk
5. Management Dashboard

## 使用
直接双击 `index.html` 即可打开。

## 当前版本
这是前端MVP演示版。AI分析目前使用本地规则演示，没有连接真实LLM/API、公司数据库或知识库。
